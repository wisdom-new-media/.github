# Contributing

Thank you for your interest in Wisdom New Media's projects.

## Before you start

Read the project's README and any project-specific contribution instructions. For a
substantial change, open an issue first to explain the problem and proposed approach.

## Reporting bugs and requesting features

Use the affected project's issue tracker. Include enough detail to reproduce a bug,
or explain the need and expected outcome for a feature.

For security vulnerabilities, follow [our security reporting guide](https://github.com/wisdom-new-media/.github/blob/main/SECURITY.md).

## Submitting a change

1. Create a focused branch in the project, or fork the repository if you do not have write access.
2. Follow the project's existing conventions and keep the change focused.
3. Run the relevant checks and update documentation when behavior changes.
4. Open a pull request describing the change, why it is needed, and how you validated it.

For documentation-only changes, check links and preview the rendered Markdown.
