# Security Reporting

Please report security vulnerabilities privately.

## How to report

In the affected public repository, open **Security → Report a vulnerability** when
private vulnerability reporting is available.

If that option is unavailable, use [Wisdom New Media's private reporting channel](https://github.com/wisdom-new-media/.github/security/advisories/new).
Include the affected repository's name so we can identify the project.

Please describe the affected component or version, potential impact, and steps to
reproduce the issue. Use minimal examples and remove credentials and personal data.

For private projects, use the project's designated internal reporting channel or
contact its maintainers directly.

## Supported versions

Each project defines its own supported versions and security update policy. Check
the project's documentation for details.
